# Perkenalan

Selamat datang di dokumentasi **AB Download Manager**!

AB Download Manager merupakan download manager gratis, cepat, dan open-source yang didesain untuk membuat unduhan file-file menjadi tanpa hambatan, teratur, dan sangat cepat. 

## Fitur Utama

- **Unduhan Cepat**: Mempercepat unduhanmu hingga 500% menggunakan koneksi multi-threaded.
- **Manajemen Antrean**: Unduh multi file secara berurutan dengan membuat antrean unduhan khusus.
- **Antarmuka yang Elegan**: Nikmati antarmuka pengguna yang cantik, modern dengan dukungan mode gelap bawaan.
- **Browser Integrasi**: Otomatis mengambil tautan dari browser-browser populer (Chrome, Firefox, Edge, Opera, dll.) menggunakan ekstensi.
- **Pembatas Kecepatan**: Kontrol berapa banyak bandwidth yang digunakan aplikasi untuk menghindari perlambatan jaringanmu.
