## Pemasangan

Kamu bisa menginstall AB Dwonload Manager dengan cara-cara berikut ini

### Unduhan langsung

- [Website Resmi](https://abdownloadmanager.com/#download): Unduh versi stabil terbaru secara langsung. Poin ini adalah pilihan yang paling sederhana untuk sebagian besar pengguna.
- [GitHub Releases](https://github.com/amir1376/ab-download-manager/releases/latest): Termasuk installer dan riwayat rilis penuh.

### Script instalasi

#### Linux (Direkomendasikan)
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amir1376/ab-download-manager/master/scripts/install.sh)
```

### Package Manager

#### Windows

##### Winget

```bash
winget install amir1376.ABDownloadManager
```

##### Scoop:

```bash
scoop install extras/abdownloadmanager
```

#### Homebrew (untuk macOS & Linux)

```bash
brew tap amir1376/tap && brew install --cask ab-download-manager
```
