# Integrasi Browser

Integrasi Ab Download Manager dengan browser memungkinkan penangkapan tautan unduhan secara otomatis, memberikan pengalaman mengunduh yang lancar.

## Browser yang Didukung

Kami mendukung web modern, termasuk:
- **Google Chrome**
- **Mozilla Firefox**
- **Microsoft Edge**
- **Brave Browser**
- **Opera**
- **Vivaldi**

## Langkah-langkah Instalasi

1. Pasang ekstensi browser yang sesuai dengan browser kamu dari chrome web store resmi atau tautan yang ada di modal unduhan.
2. Pastikan aplikasi AB Download Manager desktop sedang berjalan di latar belakang.
3. Setelah aktif, tautan yang diklik di browser akan otomatis dialihkan ke AB Download Manager.
